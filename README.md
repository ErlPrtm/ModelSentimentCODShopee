# ModelSentimentCODShopee
Model yang akan digunakan untuk Project Based Learning teknik Informatika Semester 6 di Politeknik Negeri Jakarta, digunakan untuk memberikan Sentiment Analysis dengan IndoBERT, Clustering masalah dengan K-Means serta summarization masalah terbanyak juga memberikan langkah-langkah untuk solusi masalah tersebut
